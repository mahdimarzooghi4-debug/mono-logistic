# Mono Courier Mobile

Persian RTL courier app prototype based on the Figma courier app frames `home` (`169:3`), `en-route-to-pickup` (`171:2`), `arrived-pickup` (`173:2`), and `en-route-to-dropoff` (`175:2`).

## Local preview

```sh
npm ci
npm run dev
```

The app uses the Figma demo values for the courier, wallet, mission offers, and pickup and recipient details. Availability, offer selection, mission acceptance, pickup checks, handoff confirmation, and route progress are client-side demo interactions; they are not connected to the courier API yet.
