# Mono Courier Mobile

Persian RTL courier app prototype based on the Figma courier app frames `home` (`169:3`), `en-route-to-pickup` (`171:2`), and `arrived-pickup` (`173:2`).

## Local preview

```sh
npm ci
npm run dev
```

The app uses the Figma demo values for the courier, wallet, mission offers, and pickup details. Availability, offer selection, mission acceptance, pickup checks, and handoff confirmation are client-side demo interactions; they are not connected to the courier API yet.
